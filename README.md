# AID1 Site Version 3.0

- HOMEの「WHO WE ARE / Story」を削除
- HOMEの並びを Mission → Journey → Governance → Stake Pool → Latest に変更
- 上部メニューを Home → Mission → Journey → Governance → Stake Pool → Latest → About に統一
- Aboutページを Hero / Profile / Contact のみに簡略化
- Journey専用ページ `journey.html` を新規追加
- Aboutにあった主な活動、これまでの歩み、Why AID1をJourneyへ移動
- これまでの歩みに2022年を追加

  - カルダノブースを拡大し出展を継続。
- HOMEのJourney欄に「JOURNEYの詳細を見る」リンクを追加
